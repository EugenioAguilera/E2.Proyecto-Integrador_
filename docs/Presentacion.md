# Presentación del Proyecto

AgentePETE es una aplicación desarrollada en C++ utilizando Qt y Ollama cuyo objetivo es ayudar a los usuarios a organizar tareas, actividades y compromisos mediante una interfaz gráfica intuitiva y un asistente inteligente local.

El sistema permite registrar tareas, consultar pendientes, administrar información personal y recibir recomendaciones generadas por inteligencia artificial.

Tecnologías utilizadas:

* C++
* Qt Framework
* Ollama
* GitHub
* CMake
