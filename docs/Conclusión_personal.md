# Conclusión Personal

Durante el desarrollo de AgentePETE fortalecí mis conocimientos de programación orientada a objetos, trabajo colaborativo mediante GitHub y control de versiones.

Mi contribución principal consistió en el desarrollo del módulo de historial de conversación y estadísticas de conversación, permitiendo almacenar y analizar la interacción entre el usuario y el asistente.

También adquirí experiencia utilizando Qt, CMake y metodologías de trabajo similares a las empleadas en equipos profesionales de desarrollo de software.
